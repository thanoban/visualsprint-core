# Roadmap

Solo-dev week estimates. **This file describes what's built.** For what's actually
working in the live `visualsprint-agent` deployment right now — including the
2026-08-18 incident where every capture path was found to have zero meetings ever
captured — see [docs/14-production-status.md](14-production-status.md).

| Phase | Weeks | Deliverable |
|---|---|---|
| **0. Foundations** ✅ | 1–2 | Monorepo, schema, FSM orchestrator, blob store, all six swap-point interfaces — **runtime-verified**: migration applied, upload→acquire→transcribe proven end-to-end (`tests/test_upload_pipeline.py`) |
| **0b. ASR baseline** | 1–3 | Eval harness ✅ implemented + unit-tested (WER, code-switch WER, switch-point F1, entity accuracy, provider ranking, frozen-report regression gate); consented gold set, live Google/Azure bake-off, and reviewed baseline not started |
| **1. Capture** | 3–6 | **Mode D upload** ✅ runtime-verified. Mode A2 artifacts ✅ wired for Meet, Zoom Cloud Recording, and Teams (`worker.py::_get_platform_adapter_for_session`) — every platform resolves a real per-org `OAuthTokenProvider` once that org connects (`frontend/app/settings/connections`), falling back to a specific "not connected" error otherwise; no shared-credential risk across orgs (fixed this session). **A1 RTMS** ✅ — Zoom webhook receiver + live-stream client, with per-org account routing (`app/api/rtms_webhook.py::_resolve_org_for_zoom_account`) so multiple customers' meetings land in the right org, not one hardcoded default. **Calendar watch** ✅ (google + microsoft) wired into the worker's poll loop, same per-org OAuth. **Disclosure** ✅ (`app/capture/consent.py`, every mode writes a `ConsentRecord`). **Coverage telemetry** ✅ (`coverage_interval` rows, flagged on overlapping knowledge items). All OAuth *plumbing* is done and tested against fakes — what's actually blocked is registering the seven real vendor apps (Google, Microsoft, Slack, Jira, GitHub, Linear, Zoom) and filling in their client id/secret, which only the account owner can do |
| **2. ASR cascade** | 4–7 | VAD + LID + routing + failover ✅ implemented (`backend/app/asr/`, `backend/app/adapters/asr_*.py`) and wired into the pipeline's `transcribe` stage (`worker.py::_get_transcriber`), but **not runtime-verified against real audio/vendor credentials** — the walking-skeleton test substitutes a fake Transcriber. LLM repair pass ✅ implemented (`backend/app/asr/repair.py`) using roster + screen OCR, wired into `transcribe` end-to-end (proven with a fake LlmClient, not live Vertex AI). **Correction UI + glossary flywheel** ✅ (`frontend/app/meetings/[id]/correct/page.tsx`, `frontend/app/glossary/page.tsx`, `GlossaryTerm` model) |
| **3. Understanding** | 7–12 | Keyframes ✅, OCR ✅, optional VLM captions ✅ wired through `LlmVisionCaptioner` and persisted to `Keyframe.vlm_caption` when configured; caption failures degrade to a blank caption while OCR/grounding still complete. Speech↔screen grounding ✅ — all wired into the `screen` pipeline stage between `transcribe` and `understand` (`backend/app/orchestrator/worker.py::_handle_screen`), proven end-to-end with fakes (no opencv/PaddleOCR/Vertex vision required to test). A video-format Mode D upload doubles as the screen source; audio-only uploads produce zero keyframes as a normal, non-failing outcome. Five agents ✅, evidence + confidence ✅. Live Vertex vision smoke test not run |
| **4. Memory + Chat** | 11–15 | Lifecycle edges ✅, hybrid retrieval ✅ (FTS always on, pgvector when embeddings exist), **org-memory chat with evidence chips** ✅ — MongoDB acceptance path is covered by tests. Memory Intelligence now treats Vertex embeddings as optional: missing credentials degrade to keyword-overlap search instead of failing the `remember` stage. Live Vertex embedding smoke test not run |
| **5. Product + Automation** | 14–18 | Report UI ✅, coverage display ✅ (report banner + chat), action-approval UI ✅ (`frontend/app/actions/page.tsx`). All six MVP automations ✅ have connectors (`app/connectors/`): follow-up email, Slack/Teams recap, Jira/GitHub/Linear task, calendar follow-up, blocker escalation, commitment reminder. Each resolves a real per-org `OAuthTokenProvider` at approval time (`app/api/actions.py::_get_connector`, no shared-singleton risk across orgs), falling back to `UnconfiguredTokenProvider` only when that org hasn't connected the vendor yet. Jira converted off Basic-auth-with-a-pasted-token onto real OAuth 2.0 3LO. Escalation/reminder are also the only two with a **deterministic** (non-LLM) trigger (`app/orchestrator/action_triggers.py`): recurring-blocker and due-date-approaching sweeps, not just LLM judgment on a single meeting's items. Disconnect/revoke ✅ (`DELETE /api/v1/orgs/{org_id}/connections/{provider}`, `app/api/oauth.py`) -- deletes both the connection row and its secret; does not call the vendor's own token-revocation API (not universally offered), so the frontend directs users to the vendor's own connected-apps page for a full server-side revoke. This line previously said this endpoint was missing; it already existed and was verified working before that claim was corrected on 2026-08-11 |
| **6. Expansion** | 18+ | **Teams Graph adapter** ✅ (capture code existed, Microsoft OAuth closed the gap this session). Bot fallback (fork Vexa/Attendee) and CRM field-sync (HubSpot/Salesforce) remain **not started, deliberately** — bot fallback has no org currently blocked on official-API capture to build against, and CRM sync has no chosen vendor or field mapping; both would be speculative infrastructure with no consumer today. Pilot onboarding not started |

**First sellable slice — end of Phase 4 (~4 months):** Zoom + Meet capture, tri-lingual transcription, evidence-graded knowledge, cross-meeting memory, chat. Phase 5 reaches automation parity with Fireflies/Fathom.

## Parallel workstream: consent & compliance

Sri Lanka PDPA (No. 9 of 2022) + platform ToS + recording-consent law. Disclosure, join policy, retention windows, export/deletion built in from Phase 0 — not retrofitted. **Requires local legal review before pilot** — this plan flags requirements; it does not assert what the law permits.
